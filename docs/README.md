# Portfolio — site statique

Ce répertoire contient un **site de présentation statique en français**, sans moteur applicatif, sans cookies analytiques et sans collecte de formulaire. Le seul appel à l'action dirige vers le profil Malt.

## Publication sur GitHub Pages

Le site est prêt à servir à partir de `/docs`, mais sa publication **n'est pas implicite** : dans les paramètres de ce dépôt, ouvrir **Settings → Pages**, choisir **Deploy from a branch → main → /docs**, puis enregistrer. Vérifier l'URL et le HTTPS dans GitHub avant de diffuser une adresse publique. L'activation de GitHub Pages n'est pas automatisée par ce dépôt.

## Sources et transparence

- `index.html` : page de présentation, missions, réalisations, contact.
- `style.css` : styles responsive, accessibles sans JavaScript.
- `METHODE_MIGRATION_FR.md` : méthode proposée, pas un cas client.
- La capture CYBOU Browser provient de son **dépôt réel**. Elle représente une version alpha de développement.
- Les projets sont personnels et ne sont pas présentés comme livraisons commerciales, certifications ni références clients.

Mettre à jour les liens et statuts de projet à chaque changement important, puis vérifier que les ressources sont accessibles publiquement.
